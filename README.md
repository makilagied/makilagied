# Hi, I'm Erick D. Makilagi 👋

**Turning business problems into working systems**

I'm a full-stack engineer in Dar es Salaam 🇹🇿. Most of my work sits where money and data move: banking operations, the Dar es Salaam Stock Exchange (DSE), investment funds and payments. I build the web apps, mobile apps, APIs and automation behind them.

- 🏦 **Finance:** reconciliation tools, fund (NAV) systems, DSE market data
- 📱 **Mobile:** React Native (Expo) and Flutter apps
- 🌐 **Web:** Angular, Next.js and React front ends on Spring Boot, FastAPI and Node.js back ends
- ⚙️ **Automation:** Python jobs that replace spreadsheets and manual checks
- 🏥 **Integration:** healthcare data interoperability (FHIR, OpenFn)
